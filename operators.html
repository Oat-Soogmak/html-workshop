เจาะลึกรายชื่อหน่วยรบ (Operators Intel)

ตัวละครใน Delta Force แบ่งตามสายอาชีพเฉพาะทางเพื่อการทำงานเป็นทีมอย่างมีประสิทธิภาพ

Assault Class

Kai Silva (Direwolf)

หน่วยจู่โจมแนวหน้า เน้นการเข้าทำอย่างรวดเร็วและพังแนวป้องกันศัตรู

  • Tactical Skill: Triple Blaster (ยิงลูกระเบิดติดผนัง)
  • Ultimate Skill: Motorized Exoskeleton (เพิ่มความเร็วเคลื่อนที่และรีโหลด)
  • Passive: คล่องตัวสูงเมื่อสังหารศัตรูได้
Recon Class

Luna Kim (Luna)

หน่วยสอดแนม ค้นหาและระบุตำแหน่งเป้าหมายให้เพื่อนร่วมทีม

  • Tactical Skill: Detection Arrow (ยิงธนูเปิดสแกนตำแหน่งศัตรู)
  • Ultimate Skill: Volt Arrow (ธนูกระแสไฟฟ้าสร้างความเสียหายวงกว้าง)
  • Passive: ตรวจจับการเคลื่อนไหวของศัตรูเมื่อศัตรูยิงปืน
Support Class

Roy Smee (Stinger)

หมอสนาม คอยรักษาและอำพรางตัวให้ทีมในสถานการณ์ฉุกเฉิน

  • Tactical Skill: Therapeutic Drone (ปล่อยโดรนฉีดสารฟื้นฟูเลือด)
  • Ultimate Skill: Smokescreen Drone (สร้างแนวควันอำพรางพื้นที่ใหญ่)
  • Passive: ชุบชีวิตเพื่อนร่วมทีมได้เร็วกว่าปกติ
Engineer Class

Terry Shepherd (Shepherd)

วิศวกรและผู้เชี่ยวชาญการต่อต้านยานพาหนะและการป้องกันพื้นที่

  • Tactical Skill: Sonic Paralysis (คลื่นเสียงทำให้ศัตรูช้าลง)
  • Ultimate Skill: Defense Drone (โดรนทำลายลูกระเบิดและจรวดที่เข้ามา)
  • Passive: ลดความเสียหายจากแรงระเบิด
